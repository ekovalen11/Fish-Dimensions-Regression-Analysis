Отчёт по лабораторной работе №1 (EDA)

1. Постановка задачи
Целевая переменная — масса рыбы (`Weight`). Входные признаки — геометрические размеры (`Length1`, `Length2`, `Length3`, `Height`, `Width`) и категория вида (`Species`). Цель — провести воспроизводимый исследовательский анализ, найти проблемы качества и сформулировать гипотезы.

2. Воспроизведение исходного состояния
- Исходный репозиторий: `https://github.com/tylerrussin/Fish-Dimensions-Regression-Analysis`
- Исходный коммит: `1f65547b63c3043e2dcfff0c6435afa993331d4e`
- Версия Python: 3.12.3
- Установленные библиотеки: pandas, dash, dash-bootstrap-components, statsmodels, gunicorn, matplotlib, seaborn, scikit-learn, ipykernel (установлены в `.venv`).
- Исходная ошибка: `pipenv` не смог создать окружение на Python 3.7 (ImportError). Минимальное изменение: создано окружение `.venv` на Python 3.12.3 через `python3 -m venv`. Также исправлены две несовместимости в `run.py`: удалён устаревший параметр `light=True` в `NavbarSimple` и метод `app.run_server()` заменён на `app.run()`.

3. Паспорт данных
| Поле | Тип | Единицы | Назначение | Проверки |
|------|-----|---------|------------|----------|
| Species | str | словарь категорий (7 видов) | Признак | Нет пропусков, 7 уникальных видов |
| Weight | float | граммы | Целевая переменная | > 0, но есть 1 строка с весом 0 (индекс 40) |
| Length1 | float | см | Признак | > 0, согласовано с Length2, Length3 |
| Length2 | float | см | Признак | > 0, сильно коррелирует с Length1 |
| Length3 | float | см | Признак | > 0, сильно коррелирует с Length1 |
| Height | float | см | Признак | > 0 |
| Width | float | см | Признак | > 0 |

Единица наблюдения — одна рыба. Идентификаторов и группирующих признаков нет.

4. Качество данных
- Пропусков нет ни в одном столбце.
- Полных дубликатов строк: 0.
- Обнаружена физическая аномалия: строка с индексом 40 имеет вес 0. Решение: при моделировании удалить или заменить на медиану.
- Выбросы по IQR: 3 строки (индексы 142, 143, 144) — самые тяжелые рыбы. Решение: не удалять, так как крупная рыба — ценное наблюдение.

5. Визуализация
В блокноте `notebooks/01-eda.ipynb` построено 7 графиков:
1. Распределение веса в исходной и логарифмической шкале (`log1p`).
2. Количество и распределение веса по видам.
3. Матрица парных графиков (выявлена мультиколлинеарность длин).
4. Корреляционная матрица (с оговоркой о нелинейных связях).
5. Показатели качества (уникальные значения).
6. Визуализация выбросов с указанием строк.
7. Проверка гипотезы о связи объёма и веса.

6. Гипотезы
1. Физическая гипотеза: объём (L×H×W) связан с весом сильнее, чем одна длина. Корреляция Вес-Объём = 0.949, Вес-Длина1 = 0.916. Гипотеза подтверждена.
2. Категориальная гипотеза: вес зависит от вида рыбы. Требуется кодирование `Species` (One-Hot Encoding).

7. Разбиение и проверка утечек
- Train: 111 строк, Val: 24 строки, Test: 24 строки.
- Использовано стратифицированное разбиение по `Species` (все 7 видов присутствуют в тесте).
